Gestión de Factura de Servicios

Descripción

Este ejercicio consiste en crear una clase en Java que represente una factura comercial. Permite registrar los datos del cliente, guardar el monto neto y calcular el total incluyendo el IVA del 21%.

Funcionamiento

* Registrar el número de factura, el cliente y el monto neto.
* Validar que el monto neto no sea negativo.
* Calcular el IVA correspondiente al 21%.
* Obtener el total de la factura sumando el monto neto y el impuesto.
* Mostrar por consola el detalle del cálculo y el total a pagar.

Conceptos utilizados

* Clases y objetos.
* Encapsulamiento.
* Constructores.
* Métodos.
* Validaciones.
* Operaciones matemáticas.

Ejemplo

Se crea una factura con los datos de un cliente y un monto neto de prueba. Luego, se calcula el IVA del 21% y se muestra el importe del impuesto junto con el total final de la factura.
